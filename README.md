# PetManager — Sistema de Gestão para Pet Shops 🐾

Sistema completo de gestão para pet shops, centros de estética animal (banho e tosa), clínicas veterinárias e daycare.

![PetManager Dashboard](https://images.unsplash.com/photo-1548767797-d8c844163c4c?w=1200&auto=format&fit=crop&q=80)

---

## 🚀 Funcionalidades Principais

- **🏠 Dashboard Gerencial:** Métricas de faturamento, indicadores de clientes, gráficos de tendência da receita, lista de serviços do dia e alertas de estoque baixo.
- **👤 CRM Tutores (Clientes):** Cadastro completo, visualização master-detail com abas (Pets, Histórico, Financeiro, Observações) e link direto para WhatsApp.
- **🐶 Ficha do Pet & Vacinas:** Informações de raça, idade, peso, restrições, temperamento, controle de vacinação com alertas e histórico completo.
- **📅 Central de Agendamentos (Multi-Profissional):** Grade horária visual por profissional, cards coloridos por tipo de serviço, mini-calendário interativo e contadores de status.
- **🛁 Banho e Tosa (Kanban em Tempo Real):** Acompanhamento do fluxo operacional (`Aguardando` ➔ `Em Banho` ➔ `Em Secagem` ➔ `Em Tosa` ➔ `Finalizado` com notificação ao tutor).
- **🛒 PDV (Frente de Caixa Rápido):** Catálogo de produtos, leitor de código de barras, carrinho dinâmico e multi-pagamentos (PIX, Cartão, Dinheiro).

- **HTML5** semântico
- **CSS3 Moderno** (Flexbox, CSS Grid, Design Tokens, Gradientes e Micro-animações)
- **JavaScript (Vanilla / ES6+)** modular e componentizado
- **Lucide Icons**
- **Google Fonts** (*Plus Jakarta Sans* e *Inter*)

## 💻 Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```
2. Abra a pasta do projeto:
   ```bash
   cd Sistema-pet
   ```
3. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Edge, Firefox) ou utilize a extensão **Live Server** no VS Code.
